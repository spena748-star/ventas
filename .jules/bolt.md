## 2026-06-10 - Optimizing Render Loops for Large Datasets
**Learning:** In vanilla JavaScript applications with large datasets (5000+ items), nested (N)$ operations such as `Array.prototype.indexOf` or `Array.prototype.find` inside a render loop create (N^2)$ bottlenecks that severely degrade UI responsiveness. Additionally, multiple passes over the same data using `reduce`, `filter`, and `map` add unnecessary overhead compared to a single `forEach` or `for` loop.
**Action:** Always prefer a single-pass loop that handles filtering, data aggregation, and HTML generation simultaneously. Use pre-calculated Map or Object lookups for (1)$ access to related data (like clients) inside the loop. Batch DOM updates by accumulating HTML strings instead of multiple `appendChild` calls.
